Problem

传统工作流的三个瓶颈

跨境采销人员接到任务，每一步都要手动搜索、整理、判断。

🔍

调研耗时 2–3 周

Amazon 热销、Google Trends、社交媒体声量分散在不同平台，汇总对齐本身就是马拉松。

⚠️

合规风险不可控

欧洲法规是双层结构——欧盟法 + 国家法。不同品类的检查路径完全不同，漏掉一条就是合规事故。

📝

文案本地化质量低

直接翻译，忽略当地流行用语、文化禁忌和广告法限制。上线后转化率远低于预期。

Why Agent

为什么不是 Workflow，而是 Agent

Workflow 查表，Agent 推理。当步骤该做什么、先做什么后做什么、甚至是否继续，都取决于输入内容时，只能用 Agent。

选品调研：数据源冲突时，Workflow 卡住，Agent 能判断

Workflow 可以按顺序调三个工具，但拿到"电商涨、社交跌、趋势平"的数据时，该信哪个？需不需要额外验证？这个判断依赖上下文，写不成��[...]

合规审查：Agent 调用 skill，Workflow 写规则

Workflow 是"if 品类 == X then 查 Y"。但新品类不断出现，规则写一条崩一条。Agent 把"查法规"封装成 skill，遇到新品类时自主判断该调用什么、��[...]

HITL 分叉：分支条件本身需要推理

Workflow 也能做路由和终止，但只能基于预设条件."高/中/低"风险不是简单查表，而是 Agent 综合品类、法规、上下文之后的判断。分支条件��[...]
